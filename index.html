🎲 Ход

  • У тебя 5 игроков и 4 хода в тайме (2 тайма). Каждый игрок действует один раз за ход.
  • Тап по своему игроку → тап по зелёной клетке = перемещение. Дальность = СКР.
  • После перемещения можно сделать одно действие на кубиках: пас, удар или отбор.

⚠️ Главное правило (как в Blood Bowl)

  • Провалил бросок — ход сразу переходит сопернику! Даже если остались действия.
  • Дубль 1-1 — катастрофа (травма), дубль 6-6 — критический успех.
  • Клетки рядом с соперником стоят дороже — защита «вяжет» атаку.

🥅 Действия

  • ПАС — 2d6 + ПАС против сложности (дистанция + давление). Провал = мяч летит в сторону, возможен перехват.
  • УДАР — только из зоны удара (5 клеток до ворот). Чем ближе и острее угол — тем легче.
  • ОТБОР — вплотную к владельцу мяча. Успех = мяч твой, провал = потеря хода.

💰 Экономика

  • Монеты за матч (победа/ничья/гол × сложность) → прокачка 5 игроков (СКР/ПАС/УДР/ОТБ) и новые схемы.
  • 🎲 Переброс — 2 бесплатных за матч, дальше за рекламу.
📋 Концепт игры
ГДД · «Тактик-Бол» · VK Games · single-player · no-backend

1. Питч

«Тактик-Бол» — пошаговый футбол на кубиках: Blood Bowl, ужатый до мобильной сессии 5–7 минут. Поле 9×12, 5 на 5, одно действие на игрока, и главное правило жанра: провалил бросок — потерял ход. Никакого сервера, вся математика и ИИ на клиенте.

2. Почему это работает в ВК

  • Тактика без APM: идеально для мобильного — думай сколько хочешь, палец один.
  • Кубики = драма: каждый бросок — микро-саспенс, а переброс — самый конверсионный rewarded-триггер в жанре.
  • Короткий матч: 8 командных ходов, 4 минуты до финального свистка → высокая частота сессий.
  • Понятный спорт: футбол не нужно объяснять, в отличие от фэнтези-сеттинга Blood Bowl.

3. Core Loop

Выбрал игрока → пошёл (без риска) → выбрал действие на кубиках (риск) → провал = смена хода → гол/потеря → ход ИИ → 4 хода = тайм → 2 тайма = матч → монеты → прокачка состава → следующий матч на более высокой сложности.

4. Механики и баланс

ДействиеФормула (2d6 + мод ≥ цель)
Пасцель = 4 + дист×0.7 − ПАС×0.6 + давление×0.9; провал → мяч разлетается, шанс перехвата
Ударцель = 5 + дист×0.85 − УДР×0.75 + угол×0.8 + мод вратаря (сложность); зона удара ≤ 5 клеток
Отборцель = 5 + ОТБ соперника×0.5 − свой ОТБ×0.7; дубль 1 → травма
ПеремещениеДейкстра: клетка = 1 очко, +1 если рядом соперник (зона прессинга), СКР = бюджет

Травмы игрок выбывает до конца матча → ценность слота «Доктор».
Крит-правила 1-1 = провал+травма, 6-6 = автоуспех и бонус (гол с любой дистанции / идеальный пас).
Камбэк-баланс проигрывающая команда получает +1 к броскам во 2-м тайме (rubber-band, удерживает напряжение до финала).

6. Ретеншн

  • Прокачка состава: 5 игроков × 4 стата (1→6). Долгая цель — «шестёрки» у всех (~18–22 матча).
  • Схемы: «Классика 1-2-2» (0), «Стена 2-3» (600), «Стрела 1-1-3» (1400) — меняют тактику старта.
  • 3 уровня сложности с множителем наград x1.0 / x1.6 / x2.4 — вертикальная прогрессия мастерства.
  • Статистика тренера: победы, голы, серия побед; локальный «Рекорд дня».
  • Шеринг ВК (+100 монет раз в матч) — виральная петля.

7. Техническая архитектура (сервера нет)

  • Phaser 3 CDN Boot-сцена генерирует все текстуры кодом (фишки, мяч, грани кубиков, тени) — 0 внешних ассетов, загрузка < 1 с.
  • Scale.RESIZE + пропорциональная сетка: поле пересчитывается на любой диагонали, без леттербокса.
  • CSS-оверлей HUD, панель действий, экраны — отдельные DOM-слои с pointer-events; канвас ловит только тапы по полю.
  • ИИ конечный автомат + дейкстра: оценка «бить/пасовать/вести», поддержка атаки и маркировка в защите; 3 профиля через модификаторы бросков.
  • Детерминированность один ГСЧ-поток, все броски честные (без «резиновых» исходов), античит не нужен — награды только косметика/прогресс.
  • Хранение localStorage (синхронно) + VK Cloud Storage через Bridge (между устройствами). Конфликт сейвов решается слиянием по максимуму.
  • Звук WebAudio-синтез: свисток, стук кубиков, рев трибун, удар, отбор — 0 КБ ассетов.
  • VK Bridge Init · SetViewSettings · GetUserInfo · ShowRewardedVideo (+Result/Failed/DidClose) · StorageGet/Set · TrackEvent · Share. Вне ВК — заглушка rewarded для QA.

9. Метрики

D1 ≥ 34% · D7 ≥ 13% · матч 4–7 мин · 2.8+ сессии/день · ARPDAU 5–8 ₽ · CR переброса ≥ 38% · доля матчей на «ПРО» к D7 ≥ 25%

10. Роадмап

  • Кубок из 3 матчей с боссами-командами (у каждой свой «характер» ИИ: автобус, прессинг, контратака).
  • Карточки умений игроков («Дальний удар», «Стенка», «Финт») —draft за монеты между таймами.
  • Лидерборд друзей ВК (Bridge) и еженедельный «Матч дня» с фиксированным сидом поля — честное сравнение без сервера.
