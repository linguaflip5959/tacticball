⚽ ТАКТИК-БОЛ
Пошаговый футбол на кубиках (Blood Bowl-lite) — игра для VK Games.Матч 4–7 минут: поле 9×12, 5 на 5, главное правило жанра — провалил бросок, потерял ход.

Стек
Phaser 3.80 (CDN) — рендер
Чистый JS, ES-модули, без сборщика
0 внешних ассетов: текстуры генерируются кодом, звук синтезируется WebAudio
VK Bridge: rewarded-реклама, облачные сейвы, шаринг
Запуск
ES-модули не работают с file:// — нужен любой локальный сервер:

npx servepython -m http.server
Отладка: открой index.html?debug — в консоли браузера появится window.TB(TB.hurt(i) — травмировать игрока, TB.info() — состояние матча).

Структура
index.html — экраны и HUDcss/style.css — стилиjs/ — 10 ES-модулей (ядро матча — match.js)docs/ — ГДД и легаси
Статус
Ядро играет от свистка до свистка (история патчей P0→P4, P2b — в коммитах).Дальше: публикация в ВК → плейтест → контент (карточки умений, турниры за рекламу).
