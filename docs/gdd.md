    <div class="h2">📋 Концепт игры</div>
    <div class="sub2">ГДД · «Тактик-Бол» · VK Games · single-player · no-backend</div>
    <div class="gdd">
      <h3>1. Питч</h3>
      <p><b>«Тактик-Бол»</b> — пошаговый футбол на кубиках: Blood Bowl, ужатый до мобильной сессии 5–7 минут. Поле 9×12, 5 на 5, одно действие на игрока, и главное правило жанра: <b>провалил бросок — потерял ход</b>. Никакого сервера, вся математика и ИИ на клиенте.</p>
      <h3>2. Почему это работает в ВК</h3>
      <ul>
        <li><b>Тактика без APM</b>: идеально для мобильного — думай сколько хочешь, палец один.</li>
        <li><b>Кубики = драма</b>: каждый бросок — микро-саспенс, а переброс — самый конверсионный rewarded-триггер в жанре.</li>
        <li><b>Короткий матч</b>: 8 командных ходов, 4 минуты до финального свистка → высокая частота сессий.</li>
        <li><b>Понятный спорт</b>: футбол не нужно объяснять, в отличие от фэнтези-сеттинга Blood Bowl.</li>
      </ul>
      <h3>3. Core Loop</h3>
      <p>Выбрал игрока → пошёл (без риска) → выбрал действие на кубиках (риск) → <b>провал = смена хода</b> → гол/потеря → ход ИИ → 4 хода = тайм → 2 тайма = матч → монеты → прокачка состава → следующий матч на более высокой сложности.</p>
      <h3>4. Механики и баланс</h3>
      <table>
        <tr><th>Действие</th><th>Формула (2d6 + мод ≥ цель)</th></tr>
        <tr><td>Пас</td><td>цель = 4 + дист×0.7 − ПАС×0.6 + давление×0.9; провал → мяч разлетается, шанс перехвата</td></tr>
        <tr><td>Удар</td><td>цель = 5 + дист×0.85 − УДР×0.75 + угол×0.8 + мод вратаря (сложность); зона удара ≤ 5 клеток</td></tr>
        <tr><td>Отбор</td><td>цель = 5 + ОТБ соперника×0.5 − свой ОТБ×0.7; дубль 1 → травма</td></tr>
        <tr><td>Перемещение</td><td>Дейкстра: клетка = 1 очко, +1 если рядом соперник (зона прессинга), СКР = бюджет</td></tr>
      </table>
      <p><span class="pill">Травмы</span> игрок выбывает до конца матча → ценность слота «Доктор».<br>
      <span class="pill">Крит-правила</span> 1-1 = провал+травма, 6-6 = автоуспех и бонус (гол с любой дистанции / идеальный пас).<br>
      <span class="pill">Камбэк-баланс</span> проигрывающая команда получает +1 к броскам во 2-м тайме (rubber-band, удерживает напряжение до финала).</p>
      <h3>5. Монетизация — 3 rewarded-слота</h3>
      <table>
        <tr><th>Слот</th><th>Триггер (пик эмоции)</th><th>Награда</th><th>Лимит</th></tr>
        <tr><td><b>1. «Переброс»</b></td><td>Моментально после провала ключевого броска — панель поверх поля</td><td>Перебросить 2d6</td><td>2 бесплатных + 2 за рекламу на матч</td></tr>
        <tr><td><b>2. «Доктор»</b></td><td>Травма лидера / проигрываем во 2-м тайме</td><td>Лечит всех травмированных + возвращает им действие</td><td>1 на матч</td></tr>
        <tr><td><b>3. «x2 монет»</b></td><td>Финальный свисток, экран итогов</td><td>Удвоение награды за матч</td><td>1 на матч</td></tr>
      </table>
      <p><span class="pill">Честность</span> Переброс не гарантирует успех — только второй шанс. Никакого pay-to-win: ИИ не получает бонусов от того, что игрок не смотрит рекламу. <span class="pill">Цель</span> 1.8–2.6 просмотра на сессию (2 слота внутри матча + 1 после).</p>
      <h3>6. Ретеншн</h3>
      <ul>
        <li><b>Прокачка состава</b>: 5 игроков × 4 стата (1→6). Долгая цель — «шестёрки» у всех (~18–22 матча).</li>
        <li><b>Схемы</b>: «Классика 1-2-2» (0), «Стена 2-3» (600), «Стрела 1-1-3» (1400) — меняют тактику старта.</li>
        <li><b>3 уровня сложности</b> с множителем наград x1.0 / x1.6 / x2.4 — вертикальная прогрессия мастерства.</li>
        <li><b>Статистика тренера</b>: победы, голы, серия побед; локальный «Рекорд дня».</li>
        <li><b>Шеринг ВК</b> (+100 монет раз в матч) — виральная петля.</li>
      </ul>
      <h3>7. Техническая архитектура (сервера нет)</h3>
      <ul>
        <li><span class="pill">Phaser 3 CDN</span> Boot-сцена генерирует <b>все</b> текстуры кодом (фишки, мяч, грани кубиков, тени) — 0 внешних ассетов, загрузка &lt; 1 с.</li>
        <li><span class="pill">Scale.RESIZE</span> + пропорциональная сетка: поле пересчитывается на любой диагонали, без леттербокса.</li>
        <li><span class="pill">CSS-оверлей</span> HUD, панель действий, экраны — отдельные DOM-слои с <code>pointer-events</code>; канвас ловит только тапы по полю.</li>
        <li><span class="pill">ИИ</span> конечный автомат + дейкстра: оценка «бить/пасовать/вести», поддержка атаки и маркировка в защите; 3 профиля через модификаторы бросков.</li>
        <li><span class="pill">Детерминированность</span> один ГСЧ-поток, все броски честные (без «резиновых» исходов), античит не нужен — награды только косметика/прогресс.</li>
        <li><span class="pill">Хранение</span> localStorage (синхронно) + VK Cloud Storage через Bridge (между устройствами). Конфликт сейвов решается слиянием по максимуму.</li>
        <li><span class="pill">Звук</span> WebAudio-синтез: свисток, стук кубиков, рев трибун, удар, отбор — 0 КБ ассетов.</li>
        <li><span class="pill">VK Bridge</span> Init · SetViewSettings · GetUserInfo · ShowRewardedVideo (+Result/Failed/DidClose) · StorageGet/Set · TrackEvent · Share. Вне ВК — заглушка rewarded для QA.</li>
      </ul>
      <h3>8. Аналитика (TrackEvent)</h3>
      <p><span class="pill">match_start:{diff}</span><span class="pill">goal:{team}</span><span class="pill">turnover:{reason}</span><span class="pill">roll_fail:{action}</span><span class="pill">reroll_free</span><span class="pill">ad_show:{slot}</span><span class="pill">ad_reward:{slot}</span><span class="pill">injury</span><span class="pill">match_end:{result,score}</span><span class="pill">upgrade:{stat}</span><span class="pill">formation_buy</span><span class="pill">share</span></p>
      <h3>9. Метрики</h3>
      <p><span class="kpi">D1 ≥ 34%</span> · <span class="kpi">D7 ≥ 13%</span> · <span class="kpi">матч 4–7 мин</span> · <span class="kpi">2.8+ сессии/день</span> · <span class="kpi">ARPDAU 5–8 ₽</span> · <span class="kpi">CR переброса ≥ 38%</span> · <span class="kpi">доля матчей на «ПРО» к D7 ≥ 25%</span></p>
      <h3>10. Роадмап</h3>
      <ul>
        <li>Кубок из 3 матчей с боссами-командами (у каждой свой «характер» ИИ: автобус, прессинг, контратака).</li>
        <li>Карточки умений игроков («Дальний удар», «Стенка», «Финт») —draft за монеты между таймами.</li>
        <li>Лидерборд друзей ВК (Bridge) и еженедельный «Матч дня» с фиксированным сидом поля — честное сравнение без сервера.</li>
      </ul>
